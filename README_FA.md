# دفتر حساب من

نسخه اولیه پروژه اندروید (Kotlin + SQLite)، با رابط فارسی و راست‌چین.

## امکانات
- ثبت مشتری
- ثبت شرح آزاد کالا و مبلغ به تومان
- ثبت دریافت وجه
- مانده خودکار هر مشتری
- تاریخ شمسی خودکار
- حذف تراکنش با لمس طولانی
- خروجی JSON و ذخیره از طریق انتخاب‌گر اندروید (از جمله Google Drive در صورت نصب)
- ارسال نسخه پشتیبان از طریق برنامه ایمیل
- بازیابی از فایل پشتیبان

## ساخت APK
1. Android Studio را نصب کن.
2. پوشه پروژه را باز کن.
3. منتظر بمان Gradle Sync کامل شود.
4. از منوی Build گزینه Build APK(s) را بزن.

## نکته درباره Gmail
در نسخه فعلی، فایل JSON به‌صورت پیوست از طریق پنجره اشتراک‌گذاری اندروید آماده می‌شود. Gmail را انتخاب کن و ایمیل را خودت ارسال کن؛ ارسال خودکار بدون تأیید کاربر انجام نمی‌شود.

## نکته درباره Google Drive
در ذخیره فایل، اگر Google Drive روی گوشی نصب و به حساب وارد شده باشد، می‌توان آن را از انتخاب‌گر محل ذخیره انتخاب کرد. همگام‌سازی خودکار ابری در این نسخه پیاده‌سازی نشده است.

## محدودیت نسخه اولیه
این پروژه سورس اولیه است و APK کامپایل‌شده/تست‌شده نیست. پیش از استفاده واقعی، باید در Android Studio ساخته و روی گوشی آزمایش شود. در نسخه فعلی، ویرایش تراکنش و قفل/رمزگذاری فایل پشتیبان هنوز اضافه نشده است.

## ساخت APK با GitHub Actions (بدون Android Studio)
1. یک مخزن جدید و ترجیحاً Private در GitHub بساز.
2. تمام محتویات این پوشه را در ریشه مخزن بارگذاری کن؛ پوشه مخفی `.github` نیز باید بارگذاری شود.
3. از زبانه Actions، گردش‌کار `Build Android APK` را اجرا کن. با هر بار بارگذاری روی شاخه `main` نیز خودکار اجرا می‌شود.
4. پس از سبز شدن اجرای workflow، پایین صفحه اجرای آن در بخش Artifacts فایل `DaftarHesabMan-APK` را دانلود کن.
5. ZIP دانلودشده را استخراج کن و `app-debug.apk` را روی گوشی نصب کن.

این APK از نوع debug و برای تست شخصی است. ساخت ابری به اینترنت نیاز دارد. اگر بارگذاری از موبایل پوشه `.github` را نشان نمی‌دهد، در فایل‌منیجر نمایش فایل‌های مخفی را فعال کن.
